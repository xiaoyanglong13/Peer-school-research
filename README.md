# Peer School Research

This repository hosts a shareable dashboard for peer-school research.

## Current dashboard

- **Michigan State University Broad College — Supply Chain Management major mix**
- Includes declared-major shares, headcounts, a newer SCM enrollment signal, clickable source links, and hoverable methodological caveats.

## Website

The dashboard is served from `index.html`. Once GitHub Pages is enabled for the `main` branch and repository root, the public site will be available at:

`https://xiaoyanglong13.github.io/Peer-school-research/`

## Data provenance

The dashboard is based on publicly available Michigan State University / Broad College materials. Source links are embedded directly beside the relevant figures in the dashboard.
